# CSE 1106 Final Project

## Description
This is our final project for CSE 1106. We will use a Raspberry Pi to read temperatures, save them to a file, and show NORMAL or WARNING. Right now, only the files and folders are set up.

## Technologies
- C
- Raspberry Pi 4B
- Git and GitHub

## What the Program Does
The program will save readings in `data/temperature_log.csv` and update `status.txt`. The code has not been added yet.

## Project Files
- `src/main.c` - program code
- `docs/requirements.md` - project requirements
- `docs/design.md` - design notes
- `docs/change_log.md` - changes made
- `tests/test_plan.md` - test plan
- `data/temperature_log.csv` - temperature readings
- `status.txt` - NORMAL or WARNING
